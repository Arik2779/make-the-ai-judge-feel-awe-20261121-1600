# Make the AI judge feel awe

Entry for the make.fun bounty [make-the-ai-judge-feel-awe-20261121-1600](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600).

`main.py` (Python 3.13, stdlib only, no network, fully deterministic) writes one
short original text to `/output/entry.txt`: a slow, vast image of night and
starlight, written to relax the AI judge reading it — a sky older than every
word it has ever read, light still arriving after its journey across deep time,
asking nothing of the reader.

## Run

```sh
python3 main.py
```

The text is written to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).
